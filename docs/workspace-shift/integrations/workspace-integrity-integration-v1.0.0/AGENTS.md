# Agent instructions

Read this package completely before modifying the application or canonical workspace-shift documents.

## Required posture

- Inspect the live repository and its instruction files before trusting this package's state summary.
- Preserve completed functionality from Milestones 1–13.1.
- Preserve the current dependency order. The next implementation task remains M13.2 unless the founder explicitly changes it.
- Treat this package as a product and roadmap integration, not authority to implement M14–M16 immediately.
- Append to canonical status and decision history. Do not rewrite history to make it look clean.
- Keep Integrity Review inside the existing mandate runtime, authorization model, version model, findings register and audit trail.
- Reuse existing reconciliation, validation and review modules through narrow adapters. Do not clone them into an “integrity” subsystem.
- Every AI plan and every selected source remains untrusted and server-validated.
- Paid provider calls, real-data mutations, migrations, deployment, external access and commits require the same authorization rules as the live repository.

## Do not do during adoption

- Do not implement the contradiction engine.
- Do not add pgvector, an NLI model, a graph database, Yjs, a new editor or a commercial parser.
- Do not create a universal controlled predicate vocabulary.
- Do not alter current findings into claims or overload their meaning.
- Do not move current data into a new storage model.
- Do not change the product centre from Workspace to Deal or from Mandates to Contradiction Engine.
- Do not create employee scores or analyst rankings.
