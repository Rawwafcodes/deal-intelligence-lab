# Task 17.2 — Decision Packages in React
Status: complete
Authorization: founder directive, 2026-09-27 (Phase A2 of
`17.0-product-integration-program.md`).
Dependencies: 17.1 (establishes the pattern of reusing workspace-scoped
routes and cross-referencing findings by id - reused again here for
`source_finding_ids`/`source_request_ids`).

## User outcome
From a deal's Findings screen, a user can open a "Decision package" deep
page for the same workspace, see every drafted version (title, executive
summary, recommendation, key evidence, outstanding matters, risks,
status, lineage to the mandate/run that produced it), see whether the
current version is stale relative to later evidence, and - if they are
the deal lead - approve it. No normal workflow requires the unlinked
`workspace.html`'s `package.html` export or a hand-typed URL.

own docstring on the deal-lead-only v1 permission scope);
`version_dependencies.get_staleness`, already called by

4. `Findings.tsx`: add a link to the new route (a deep page, not a

## Exclusions
- **No "return" or "reject" action** - the real backend has none. Not
  invented here.
- **No "create decision package" button** - the real backend has no
  create route; a new version is only ever produced by the
  `decision_package.produce_draft` mandate capability. This screen is
  view/approve only; starting a new decision-package mandate is Phase
  C's (the unified composer's) job, once that composer exists.
- No change to `deliverables.py`, `decision_package.py`, or
  `version_dependencies.py` - pure frontend reuse of already-returned
  fields.
- No change to the deal-lead-only approval role gate.

## Reuse
100% existing backend routes/fields. `Findings.tsx`'s workspace-picker
pattern is copied, not abstracted into a shared hook in this task - a
premature abstraction for two call sites; revisit if a third workspace-
scoped page needs the same picker.

## Security and intelligence boundary
No AI involved in this task. Approval authorization is the existing

convenience only and never the actual gate.
