## 3. Accessibility check

Method: axe-core 4 via `@axe-core/playwright`, WCAG 2.0/2.1 A and AA rule
sets, 16 pages (Home, Deals, org Mandates, and every deal page including
the expanded Finding Detail and the external executive's Overview), in the
app's dark theme. Plus a keyboard-only pass on Findings.

| Result | Detail |
|---|---|
| Automated scan | Before: 8 `select-name` violations (critical) on 5 pages. After `87756f4`: **0 violations on all 16 pages**, including colour contrast. |
| Keyboard | Tab reaches each finding row; Enter expands it (`aria-expanded` updates); visible 2px focus outline; tab order runs evidence links → review decision → severity → resolution → owner → notes → next finding. Disabled "Save review" is correctly skipped until something changes. |
| Not covered | Screen-reader walkthrough (VoiceOver/NVDA), light theme, zoom to 200%/reflow at 320px, reduced-motion. Automated tools catch roughly a third of WCAG issues; this is a floor, not a certification. |
